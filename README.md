# Plus Smart Home Tech

## Общая информация
Проект представляет собой систему управления устройствами умного дома.
Система предназначена для обработки телеметрии устройств, маршрутизации данных через хабы и управления коммерческими операциями (заказы, доставка и оплата устройств).

**Технологический стек**: Java 21, Spring Boot, Spring Data JPA, Spring Cloud(Eureka, Gateway, OpenFeign, ConfigServer), PostgreSQL, Maven, REST, gRPC, Kafka, Docker, Lombok.

---

## Архитектура системы
Проект реализован с использованием микросервисной архитектуры и организован как multi-module Maven проект.
- инфраструктурные сервисы (infra)
- сервисы обработки телеметрии (telemetry)
- коммерческие сервисы (commerce)

## Инфраструктурные сервисы (infra)
Обеспечивают работу всей микросервисной системы.

### Config Server
Централизованное управление конфигурацией сервисов.

### Discovery Server
Сервис регистрации микросервисов (service discovery).

### API Gateway
Единая точка входа для клиентских запросов.

Функции:
- маршрутизация запросов
- взаимодействие с микросервисами
- централизованный доступ к API

## Сервисы телеметрии (telemetry)
Отвечают за сбор и обработку данных с устройств умного дома.

### Collector
Получает телеметрию от устройств.

Функции:
- приём данных с устройств
- отправка данных в систему обработки

### Aggregator
Агрегирует данные телеметрии.

Функции:
- обработка входящих данных
- подготовка агрегированных показателей

### Analyzer
Анализирует телеметрические данные.

Функции:
- анализ показателей устройств
- обработка событий системы

### Serialization
Модуль сериализации сообщений для передачи данных между сервисами.
Используется для:
- сериализации сообщений
- стандартизации формата обмена данными

## Коммерческие сервисы (commerce)
Отвечают за операции, связанные с устройствами.

### Order Service
Управление заказами устройств.

Функции:
- создание заказов
- получение информации о заказах

### Payment Service
Обработка платежей.

Функции:
- создание платежей
- обработка оплаты заказов

### Delivery Service
Управление доставкой устройств.

Функции:
- оформление доставки
- отслеживание статуса доставки

### Interaction API
Общие DTO, Feign-клиенты, исключения, перечисления

## Взаимодействие сервисов
Сервисы взаимодействуют между собой с использованием:
- gRPC — для межсервисного взаимодействия
- REST API — для внешних клиентских запросов через API Gateway
- Apache Kafka — для обработки потоков событий и телеметрии
